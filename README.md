# adam-olser.github.io

Personal portfolio — [adam-olser.github.io](https://adam-olser.github.io)

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS v3
- GitHub REST API (public repos, no auth)

## Development

```bash
npm install
npm run dev
```

## Deployment

Pushes to `gh-pages` trigger a GitHub Actions build and deploy to GitHub Pages.
